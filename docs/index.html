Documentation ↗
How does this work with native tool memory?+

Each tool can keep using its own memory. Gyrus adds a project handoff built from supported local session sources. For tools other than Claude Code, the context command can also include Claude Code’s scoped memory files when available.

What does it cost?+

Gyrus is MIT-licensed software with no subscription fee. Cloud inference is billed by your chosen provider; cost depends on your history, models, and workload. Local models avoid provider inference charges and use your own hardware.

How much can I trust a card?+

Cards are model-written summaries and may omit information or retain outdated claims. Freshness information shows their coverage and known failures, not a guarantee of correctness. Verify important decisions against the repository and original evidence.

Can I edit the handoff myself?+

Add a ## Manual Notes section to a project card for text that should survive regeneration. Generated sections are rewritten when the card is rebuilt. Keep longer source material in your project’s own documentation.

Can I keep ideas without rewriting the backlog?+

Set "ideas_mode": "append" to add incoming idea notes verbatim. This preserves the existing ideas page and skips model-based merging for those notes.

Can I use it on more than one machine?+

Optional Git sync lets you use a repository you own to share the knowledge base. Keep it private: extracted notes can contain sensitive information. Local-only use does not require GitHub sync.
